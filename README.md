# الحرب العالمية الثالثة

لعبة استراتيجية كبرى بمحرك Godot 4.7. تقود دولة حقيقية في عالم يبدأ من تشرين الأول 2026: اقتصاد، جيش بأجيال أسلحة، بحث، تحالفات، نفوذ، حرب على مراحل، وسلاح نووي.

![الحالة](https://img.shields.io/badge/المرحلة-0%20و%201-orange)

## التشغيل

1. ثبّت [Godot 4.7](https://godotengine.org/download) (النسخة العادية، لا .NET).
2. افتح Godot ← Import ← اختر ملف `project.godot` في هذا المجلد.
3. اضغط F5.

أو من الطرفية:

```bash
godot --path .
```

## الاختبارات

```bash
godot --headless --path . -s tests/run_tests.gd
```

وفحص الواجهة (يمر على كل الشاشات ويحفظ لقطات PNG):

```bash
godot --path . -s tests/ui_smoke.gd -- shots
```

الاختبارات الآلية تختبر: سلامة البيانات، الحتمية، الحفظ والتحميل، أن التوقعات لا تغيّر العالم، القتال، ومحاكاة 20 سنة للتوازن مع ملخص بأكبر الاقتصادات.

## التحكم

| الإجراء | الكمبيوتر | الموبايل |
| --- | --- | --- |
| إيقاف/تشغيل | المسافة أو ▶ | ▶ |
| السرعة | 1 إلى 5 | أزرار السرعة |
| تحريك الخريطة | سحب بالفأرة | سحب بإصبع |

## البنية

```
data/    ملفات JSON: الدول، الأسلحة، الحكم، التحالفات، الأحداث، الخريطة
sim/     محرك المحاكاة الحتمي (بلا رسوميات)
game/    مدير اللعبة: الوقت والحفظ (Autoload: Game)
world/   خريطة القيادة
ui/      الشاشات واللوحات
battle/  مشاهد المعارك ثلاثية الأبعاد (لاحقاً)
assets/  الخطوط والأصول وسجل التراخيص
tests/   الاختبارات
docs/    وثيقة التصميم وخارطة الطريق
```

## التصدير لأندرويد

عند إنشاء إعداد التصدير في Godot، أضف `*.json` إلى خانة «Filters to export non-resource files» حتى تُضمَّن ملفات البيانات.

## المصادر والتراخيص

- البيانات: `data/SOURCES.md`
- الأصول: `assets/LICENSES.md`
