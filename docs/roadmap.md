- [x] فصل الطبقات: `data` ← `sim` ← `game` ← `world`/`ui`.
- [x] بيانات 25 دولة (اقتصاد، جيش بـ12 صنفاً، أجيال، موارد، شخصية)، تحالفات وعلاقات، 6 أنظمة حكم، 5 سياسات، أحداث عالمية.
- [x] خريطة العالم من Natural Earth (177 دولة) بطبقات: سياسي، قوة، اقتصاد، استقرار. تكبير بالعجلة وبإصبعين.
- [x] وقت مستمر بخمس سرعات وإيقاف، وتوقف تلقائي عند الأحداث المهمة.
- [x] اقتصاد شهري: نمو، ضرائب، ميزانية بأبواب، دين، تضخم، استقرار.
- [x] بحث بخمسة أجيال لكل فرع مع أمثلة حقيقية للمقارنة.
- [x] تصنيع بخطوط إنتاج تحتاج وقتاً.
- [x] حرب على مراحل (جو، ضربات، بحر، بر) مع الدفاع الجوي والإمداد، سقوط العواصم، والاستسلام عند انهيار الدولة.
- [x] دبلوماسية: تحسين علاقات، استثمار ونفوذ حتى التبعية السلمية، عقوبات، تحالفات، سلام.
- [x] سلاح نووي مع الاعتراض والرد والشتاء النووي.
- [x] ذكاء اصطناعي بشخصيات (حذرة، طموحة، انتهازية) وثلاث صعوبات.
- [x] شروط الفوز والخسارة كلها من وثيقة التصميم.
- [x] المستشار (أهم 3 أمور)، توقع قبل كل قرار، تقرير بعد كل معركة.
- [x] حفظ وتحميل وحفظ تلقائي شهري.
- [x] اختبارات آلية: الحتمية، الحفظ، نقاء التوقعات، القتال، محاكاة 20 سنة.

## التالي

1. **تقسيم الدول إلى مناطق** (Natural Earth admin-1) والجبهات منطقة بمنطقة. معيار القبول: «عندما أضغط على العراق تظهر مناطقه الـ18 بأسمائها العربية».
2. الكرة الأرضية ثلاثية الأبعاد بدل الخريطة المسطحة (`world/`).
3. الفرق العسكرية والقواعد الحقيقية ومدى الأسلحة.
4. سوق الموارد العالمي والتجارة.
5. الاستخبارات والعمليات السرية وضباب الحرب.
6. الفئات الداخلية (الجيش، رجال الأعمال، الشارع، رجال الدين).
7. مشاهد المعارك ثلاثية الأبعاد (`battle/`) تعرض تقرير المعركة نفسه.
8. تصدير أندرويد ومستويات الرسوميات.
