# خارطة الطريق والحالة

## ما أُنجز (المرحلة 0 وأساس المرحلة 1)

- [x] مشروع Godot 4.7 بمصيّر الموبايل، وواجهة عربية من اليمين لليسار بخطّي Cairo وNoto Kufi Arabic.
- [x] فصل الطبقات: `data` ← `sim` ← `game` ← `world`/`ui`.
- [x] بيانات 25 دولة (اقتصاد، جيش بـ12 صنفاً، أجيال، موارد، شخصية)، تحالفات وعلاقات، 6 أنظمة حكم، 5 سياسات، أحداث عالمية.
- [x] خريطة العالم من Natural Earth (177 دولة) بطبقات: سياسي، قوة، اقتصاد، استقرار. تكبير بالعجلة وبإصبعين.
- [x] وقت مستمر بخمس سرعات وإيقاف، وتوقف تلقائي عند الأحداث المهمة.
- [x] اقتصاد شهري: نمو، ضرائب، ميزانية بأبواب، دين، تضخم، استقرار.
- [x] بحث بخمسة أجيال لكل فرع مع أمثلة حقيقية للمقارنة.
- [x] تصنيع بخطوط إنتاج تحتاج وقتاً.
- [x] حرب على مراحل (جو، ضربات، بحر، بر) مع الدفاع الجوي والإمداد، سقوط العواصم، والاستسلام عند انهيار الدولة.
- [x] دبلوماسية: تحسين علاقات، استثمار ونفوذ حتى التبعية السلمية، عقوبات، تحالفات، سلام.
- [x] سلاح نووي مع الاعتراض والرد والشتاء النووي.
- [x] ذكاء اصطناعي بشخصيات (حذرة، طموحة، انتهازية) وثلاث صعوبات.
- [x] شروط الفوز والخسارة كلها من وثيقة التصميم.
- [x] المستشار (أهم 3 أمور)، توقع قبل كل قرار، تقرير بعد كل معركة.
- [x] حفظ وتحميل وحفظ تلقائي شهري.
- [x] اختبارات آلية: الحتمية، الحفظ، نقاء التوقعات، القتال، محاكاة 20 سنة.

- [x] **تقسيم الدول إلى مناطق**: 676 منطقة إدارية حقيقية (Natural Earth admin-1) بأسماء عربية، والعراق بمحافظاته الـ18. الناتج والسكان مجموع المناطق، والحرب تتقدم منطقة بمنطقة على الجبهات، والعاصمة محصنة، والمناطق المحتلة تندمج خلال سنة أو تثور، والسلام يعيد الأرض، والاستسلام يبقيها بيد المنتصر.

- [x] **الموارد والمنشآت في المناطق**: موارد كل دولة موزعة على مناطقها (نفط البصرة، المنطقة الشرقية، خوزستان...)، و705 منشآت (قواعد جوية، موانئ، مصانع، مصافٍ، محطات كهرباء، منشآت نووية). الإمداد يربطها بالقتال والإنتاج: تعطيل القواعد يشل الطيران، وفقدان المصافي يقلل الوقود، والحصار البحري يقطع الواردات. ضربات في العمق خلال المعارك، وضربة صاروخية يختار اللاعب هدفها.
- [x] **التوازن**: مضاعف قتالي أشد للأجيال، وجودة التدريب لكل دولة، والتفوق الجوي أهم على الأرض، وتقدم الجبهة تراكمي، والعاصمة محصنة، وردع نووي، وطموح توسعي للدول، وحوادث حدودية، وهدنة سنتين بعد كل سلام.

- [x] **سوق الموارد العالمي**: ستة موارد بأسعار تتغير مع العرض المتاح (الحروب، الحصار، العقوبات، احتلال المناطق) وصدمات الأحداث (أزمة نفط، جفاف، أزمة معادن، تخمة نفطية). ريع النفط والغاز جزء من ناتج مناطقه (البصرة 30% من اقتصاد العراق). أثر الأسعار وخسارة الصادرات المحاصرة في الميزانية. اتفاقيات تجارية (الاتحاد الأوروبي، أمريكا الشمالية، الخليج...) ترفع النمو وقدرة الاستيراد، وتلغيها الحرب والعقوبات.

- [x] **الفئات الداخلية**: الجيش ورجال الأعمال والشارع ورجال الدين، لكل منها رضا بأسباب واضحة (الضرائب، الدعم، التجنيد، الحرب، التضخم، العقوبات، ميزانية الجيش، نظام الحكم) ووزن حسب نظام الحكم. الرضا الموزون يدخل في الاستقرار. تغيير نظام الحكم يحتاج دعمها. الجيش الغاضب ينقلب والشارع الغاضب يثور (نهاية اللعبة للاعب، وتغيير النظام للذكاء الاصطناعي). استرضاء بالمال كل ثلاثة أشهر.

- [x] **الاستخبارات والعمليات السرية**: شبكات تجسس تُبنى بالمال وتضعف مع الوقت وتكشفها مكافحة التجسس (4 مستويات بكلفة). ضباب الحرب: الرؤية من الشبكة أو العلاقة (حليف 80، اتفاقية 40، جار 30، بعيد 15)، وما دون 60 يظهر تقديراً بهامش خطأ (القوة، الاستقرار، الأجيال، توقع الحرب، طبقة القوة على الخريطة). خمس عمليات: هجوم سيبراني، تخريب منشأة، دعم المعارضة، سرقة تقنية، تحريض الجيش، بفرصة نجاح ظاهرة وخطر انكشاف. الذكاء الاصطناعي يتجسس على أعدائه وخصومه ويعمل ضدهم، والحوادث الغامضة تصلك بلا اسم الفاعل إن لم يُكشف.

- [x] **المضائق البحرية**: ثمانية ممرات (هرمز، باب المندب، السويس، البوسفور، جبل طارق، ملقا، تايوان، بنما). المسيطر الحي يغلق الممر أو يعيد فتحه. الإغلاق يقطع صادرات من يمر تجارته به (ولا يقطع تجارة المسيطر)، يرفع التوتر العالمي، ويقصّر وصول الأسطول إلا للمسيطر وحلفائه. الممر الذي بلا دولة ممثَّلة في النسخة يبقى مفتوحاً.

- [x] **الفرق العسكرية والمدى**: القوات البرية فرق (2 إلى 14 لكل دولة) متمركزة في مناطق، تتحرك عبر أرضك وأرض حلفائك أو بحراً بين الموانئ. على الجبهة تقاتل بكامل قوتها والاحتياط بـ15%. جاهزية تنخفض بالقتال وتتعافى، وخبرة تزيد القوة. الفرق تنسحب عند سقوط منطقتها والمنتصر يتقدم. المقاتلات تعمل ضمن مداها من القواعد العاملة (600-1500 كم حسب الجيل)، والصواريخ والمسيّرات ضمن مداها من أرضك. توزيع تلقائي (للذكاء الاصطناعي دائماً وللاعب اختيارياً) أو تحريك يدوي بالضغط على الخريطة. طبقة «المدى» ورموز الفرق على الخريطة.

## ما أُنجز بعد الممرات

- مضاد الدروع ومضاد السفن والحرب الإلكترونية في التوقع والمعركة، ومخزون الأجيال.
- اتجاه واحد من ستة، وأثره مكتوب قبل الاختيار.
- استيراد السلاح من دول تصنّعه: الحليف يسلّم جيله، وغير الحليف جيلاً أقل.
- تكتيك المعركة يختاره اللاعب، والمحاكاة تحسب به.
- مسارات الفضاء والسيبراني والبرنامج النووي، وبوابة الجيل الخامس للصواريخ.
- بناء مصفاة أو مصنع أو محطة أو قاعدة أو ميناء داخل منطقة قائمة.
- نمو السكان مربوط بالغذاء والحرب.
- اتحاد سلمي يدمج الأرض و75% من الجيش، منفصلاً عن التبعية.
- جملة تعرّف كل دولة.
